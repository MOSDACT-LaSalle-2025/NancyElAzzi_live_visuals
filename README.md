**My project started as a modified from an example of Mixture Grid by Simon Greenwold.**

Initially the code was tweaked for my Korg volca. and the Spectrums were each assigned to the Left and Right chanels so each had its own reaction, 
but the final video is based on a song by Charlotte Adigery & Bolis Pupul - HAHA 

The Smileys are all images I've been taking as part of a personal Smiley Archive.
The code is mapped to an Akai MPK3

**Pad 1,5 & 6:** rotate the boxes in a random direction     
**Pad 2 & 3:** Toggle the L/R spectrums      
**Pad 7:** Pauses the Smileys
**Pad 8:** Pulses the boxes size
**Pad 4:** Strobbing

**Knob 1:** Boxes size
**Knob 2** Boxes on z axis
**Knob 3:** saturation
**Knob 4:**  Bands on z axis
**Knob 5:** Grid size
**Knob 7:** Speed of Images
**Knob 8:** # of bands
